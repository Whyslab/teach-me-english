# План развития — по итогам интервью (сентябрь 2026)

## Профиль

| Вопрос | Ответ |
|---|---|
| Кто пользуется | Только автор — личный инструмент |
| Где | Компьютер (сервер и браузер на одной машине) |
| Уровень норвежского | С нуля / A1 |
| Цели | Переезд и работа, экзамен Norskprøve, путешествия, учёба в университете |

Вывод: онбординг, аккаунты, хостинг и продвижение **не нужны**. Нужны
грамматика начального уровня, готовый стартовый словарь, тренировка письма в
сторону норвежского (для экзамена) и более простой интерфейс без лишнего шума.

## Решения

**Убрать**
* XP и уровни игрока, достижения, комбо, конфетти, недельный челлендж.
  Остаются стрик с дневной целью и графики (тепловая карта, кривая уровней, прогноз).
* 60-минутный дневной таймер. Он и так не ограничивал: сбрасывался при старте тренировки.
* 16 тем оформления → 4: системная, тёмная, светлая, «Норд».

**Добавить**
* Лимит новых слов в день (как в Anki, по умолчанию 15). Повторения не ограничены.
* Обратное письмо RU → NO: видишь перевод, пишешь норвежское слово (с æ ø å).
* Род и формы существительных: `en/ei/et`, `bestemt/ubestemt`, `entall/flertall`, режим «угадай род».
* Формы глаголов: `infinitiv — presens — preteritum — perfektum`.
* Готовая колода A1, импорт одной кнопкой.
* Произношение и грамматика по ссылкам: [Forvo](https://forvo.com/languages/no/) (живой голос носителя)
  и [Ordbøkene](https://ordbokene.no/) (официальный словарь букмола: род, формы, значения).
  Выбрано вместо API: ключи не нужны, работает для любого слова.

**Оптимизировать**
* Разбить `app.js` (≈3400 строк) на ES-модули без сборщика. Именно монолит
  породил найденные при аудите дубли функций и разошедшиеся копии разметки.

## Этапы

| # | Этап | Статус |
|---|---|---|
| 0 | Норвежский, удаление фото и видео, исправления аудита | ✅ готово |
| 1 | Упрощение: геймификация, таймер → лимит новых слов, темы, Forvo/Ordbøkene, письмо RU→NO | ✅ готово |
| 2 | `app.js` → ES-модули | ✅ готово |
| 3 | Грамматика: род и формы существительных, формы глаголов, режим «угадай род» | ✅ готово |
| 4 | Колода A1 | ✅ готово — 275 слов, `decks/a1.txt` |

Этапы 1 и 2 сделаны одной переработкой: раз интерфейс всё равно переписывался
модулями, удалённое (XP, достижения, таймер…) просто не переносилось.

### Что ещё сделано по ходу
* «Угадай из 4» и «Угадай род» управляются клавишами 1–4; оценки в карточках — тоже 1–4, как в Anki.
* В письме RU → NO ответ «верно, но без æ ø å» подсвечивается отдельно и засчитывается как «Сложно».
* Редактирование слова — в окне со всеми полями вместо contenteditable в списке.
* Список выводится страницами по 100 вместо хрупкой виртуализации по скроллу.
* Удалены: мобильная нижняя панель (приложение используется на компьютере), браузерные
  уведомления (не срабатывали никогда: показывались только при скрытой вкладке, а проверка шла при её открытии),
  перетаскиваемый таймер, `/api/timer`, `/api/register`.

### Не проверено вживую
Контейнер разработки без доступа в интернет: ссылки Forvo (`forvo.com/word/<слово>/#no`),
Ordbøkene (`ordbokene.no/nob/bm/<слово>`), коды Tatoeba (`nob`) и MyMemory (`nb-NO`)
взяты из документации сервисов.

## Не выбрано сейчас — вернуться, если изменится профиль

* **Инкрементальная синхронизация.** Нужна, только если появится второе устройство.
  Сейчас `/api/sync` заменяет словарь целиком — для одного компьютера это нормально.
* **Отказ от сервера** (чистый PWA на IndexedDB). Упростило бы установку, но
  прокси Tatoeba пришлось бы переносить.
* **Аккаунты и хостинг** — только если приложением захочет пользоваться кто-то ещё.
