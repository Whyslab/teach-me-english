Тренажёр английских слов на интервальном повторении, который живёт на твоём компьютере. Добавляешь слово — приложение цепляет к нему то, что реально помогает запомнить: перевод, пример предложения, картинку и фрагмент настоящего видео с YouTube, где это слово произносят вслух. Дальше оно само решает, когда показать слово снова — прямо перед тем, как ты бы его забыл.

Ставится как приложение (PWA) и полностью работает без интернета.

## ✨ Что умеет

* **Интервальное повторение на шести уровнях.** У каждого слова есть уровень, дата следующего показа и счётчик забываний. Ответил правильно — интервал растёт; ошибся — слово падает на уровень ниже и возвращается быстрее. Алгоритм — SM-2, тот же, что в Anki.
* **Слово в контексте, а не в вакууме.** К записи можно привязать пример с переводом, картинку и фрагмент видео: идентификатор ролика, начало, конец и строку субтитров. У слов с фрагментом появляется кнопка 🎬 — нажимаешь, и проигрывается ровно тот момент, где слово звучит, а под плеером показывается реплика с подсвеченным словом. Фрагменты привязываются офлайн — см. [Как привязать фрагменты видео](#-как-привязать-фрагменты-видео).
* **Примеры предложений из Tatoeba.** Ходят через сервер, чтобы обойти CORS.
* **Картинки, которые ищутся один раз.** Источник — [Openverse](https://openverse.org/), запасной — [Wikimedia Commons](https://commons.wikimedia.org/). Ключ API не нужен. Найденный адрес сохраняется в самой записи: Openverse даёт всего 200 анонимных запросов в сутки, а слову хватает одного.
* **Видно прогресс.** Кривая обучения по уровням, тепловая карта активности за три месяца, график за неделю, прогноз повторений, опыт и недельные задачи.
* **Работает офлайн.** Service worker кеширует оболочку, колода лежит в браузере и синхронизируется с сервером, когда тот доступен.
* **Данные твои.** Экспорт, резервная копия, восстановление и импорт встроены. Колода — файл, который принадлежит тебе, а не подписка.
* **Теги и фильтры** по уровню и по своим тегам.

## 🚀 Как запустить

Нужен Node.js 20.17 или новее — этого требует `sqlite3` 6.x.

```bash
git clone https://github.com/Whyslab/teach-me-english.git
cd teach-me-english
npm install
npm start
```

Открой <http://localhost:3000>.

Файл `vocab.db` создаётся сам при первом запуске, никаких миграций накатывать не нужно. Чтобы поставить как приложение — открой в браузере и выбери «Установить приложение» / «На главный экран».

> **Про `npm install`.** `sqlite3` собирает нативный модуль. Свежие версии npm по умолчанию блокируют install-скрипты; если после установки `require('sqlite3')` падает — выполни один раз `npm rebuild sqlite3`.

## 🔧 Как поставить сервисом

Команда выше держит приложение в терминале: закрыл окно — приложение остановилось. Чтобы оно поднималось вместе с сессией и работало само:

```bash
./deploy/install.sh
```

Скрипт проверит версию Node, поставит зависимости, соберёт нативный модуль `sqlite3`, создаст `.env` из `.env.example`, если своего ещё нет, соберёт systemd-юнит с подставленным реальным путём до репозитория, запустит его и дождётся ответа приложения, прежде чем сказать «готово». `sudo` не нужен — это user-юнит, он живёт в твоём домашнем каталоге.

```bash
systemctl --user status teach-me-english     # работает ли
journalctl --user -u teach-me-english -f     # что пишет
./deploy/uninstall.sh                        # остановить и убрать юнит
```

`uninstall.sh` убирает юнит и **не трогает** `vocab.db` и `.env` — там твои слова и настройки.

Юнит изолирован: `ProtectSystem=strict`, `ProtectHome=read-only` и единственный `ReadWritePaths` на каталог репозитория. Если перенесёшь репозиторий в другое место — перезапусти `install.sh`, чтобы пути пересобрались.

### Настройки

Скопируй `.env.example` в `.env` и поправь. У всех значений есть рабочие умолчания, так что пустой `.env` тоже подойдёт.

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `3000` | Порт, на котором слушает сервер |
| `DATABASE_PATH` | `./vocab.db` | Файл базы. Относительный путь считается от каталога приложения, а не от того, откуда ты запустил команду |
| `ALLOWED_ORIGINS` | `http://localhost:3000` | Кому можно обращаться к API, через запятую. Если открываешь приложение с телефона по адресу вроде `http://192.168.1.50:3000` — добавь этот адрес сюда, иначе браузер заблокирует запросы |

## 🎬 Как привязать фрагменты видео

Кнопка 🎬 появляется у слова только тогда, когда у него есть идентификатор ролика. Само приложение его не проставляет: фрагменты привязываются офлайн скриптами из `tools/`, которые работают напрямую с `vocab.db` при остановленном сервере.

```bash
pip install -r tools/requirements-video-mapper.txt

# 1. Найти ролик для каждого слова, у которого его ещё нет.
python3 tools/youtube_fragment_mapper.py

# 2. Заменить временные метки-заглушки на реальный момент, где слово
#    произносят — берётся из субтитров ролика.
python3 tools/refine_segments.py
```

Рабочий скрипт — `refine_segments.py`: он тянет субтитры напрямую через `yt-dlp`, умеет `--cookies-file` и `--proxy-list` на случай, когда YouTube начинает ограничивать запросы, и имеет режим `--reprocess-long` для слишком длинных фрагментов. Остальные файлы в `tools/` (`check.py`, `trim_segments.py`, `final_test.py`, `debug_sub.py`, `test_sub.py`) — более ранние итерации, оставленные для истории; в рабочий процесс они не входят.

Ни видео, ни звук никуда не скачиваются: читаются только субтитры YouTube, и в базу сохраняются четыре поля.

> Если используешь `--cookies-file` — помни, что этот файл представляет собой живой вход в твой аккаунт Google. Он в `.gitignore` не просто так: не коммить его и никому не передавай.

## 🔌 API

| Метод | Маршрут | Назначение |
|---|---|---|
| `GET` | `/api/words` | Колода |
| `POST` | `/api/sync` | Отправить локальные изменения на сервер |
| `POST` | `/api/register` | Выдать идентификатор пользователя |
| `GET` | `/api/tatoeba?word=…` | Примеры предложений (прокси ради CORS) |
| `GET` | `/api/word-image?word=…` | Картинка к слову; после первого поиска берётся из колоды |
| `GET`/`POST` | `/api/timer` | Состояние таймера сессии |

Клиент шлёт заголовок `X-User-Id`, но сервер его не читает: приложение однопользовательское, идентификатор фиксированный. `/api/tatoeba` и `/api/word-image` ограничены сотней запросов за 15 минут с одного адреса, остальные — нет.

> **Аутентификации нет.** Любой маршрут открыт всему, что может достучаться до порта. На `localhost` это нормально, в домашней сети, которой ты доверяешь, — тоже. Не пробрасывай этот порт в интернет.

## 🧪 Тесты

```bash
npm test
```

42 теста, работают на одноразовом файле SQLite, а не на твоей настоящей колоде.

`tests/api.test.js` покрывает API: правила валидации, цикл синхронизации, нормализацию тегов, границы таймера, кеш картинок и то, что оболочка приложения, service worker, манифест и favicon отдаются с правильными типами содержимого.

`tests/client.test.js` покрывает чистые функции из `app.js` — экранирование HTML, атрибутов и строк JS, а также сборку адреса фрагмента. `app.js` — один браузерный скрипт без модульной системы, поэтому объявления функций вырезаются из файла и исполняются изолированно. Способ обходной, но он даёт настоящее покрытие экранирования, не требуя сперва переписать весь фронтенд.

CI гоняет их на Node 20 и 22 плюс отдельный проход, который проверяет синтаксис всех JS-файлов и то, что каждая иконка из манифеста действительно существует.

## ⚠️ Что здесь пока криво

* `app.js` — один файл примерно на 150 КБ. Работает, но разбить его на модули — главное, что этому проекту нужно дальше.
* Фронтенд покрыт тестами только на уровне чистых функций. Отрисовка и сам режим повторения не тестируются.
* `POST /api/sync` заменяет всю таблицу слов целиком при каждом вызове. С одним устройством это нормально. С двумя — кто синхронизировался последним, тот и прав, а новые слова с другого устройства пропадут. Инкрементальное слияние — следующая настоящая задача.
* Фрагменты видео привязываются только вручную, офлайн. Кнопки «найди мне ролик для этого слова» внутри приложения нет.
