Тренажёр норвежских слов (**букмол**) на интервальном повторении, который живёт на твоём компьютере. Добавляешь слово — приложение подтягивает перевод и примеры предложений, озвучивает слово норвежским голосом и само решает, когда показать его снова: прямо перед тем, как ты бы его забыл.

Ставится как приложение (PWA) и полностью работает без интернета. Интерфейс — на русском.

## ✨ Что умеет

* **Интервальное повторение SM-2** (как в Anki): «Снова», «Сложно», «Хорошо», «Легко» (клавиши 1–4). Интервалы и история ответов хранятся на сервере.
* **Лимит новых слов в день** (по умолчанию 15, как в Anki). Повторения не ограничены, так что после импорта большой колоды не случится завала через неделю.
* **Грамматика:** род существительного (`en` / `ei` / `et`, цветом) и формы: *et hus — huset — hus — husene*, *å reise — reiser — reiste — har reist*. Кнопка «⚡ формы по правилу» заполняет регулярные формы.
* **Режимы тренировки:** карточки · письмо NO→RU · письмо RU→NO (для экзамена) · «Угадай из 4» · **«Угадай род»** · **«Формы»** · трудные слова · марафон без лимита.
* **Колода Norsk A1** — 275 частотных слов с родом, формами, примерами и переводом, добавляется одной кнопкой в окне «Импорт».
* **Произношение:** синтез речи с голосом `nb-NO` + ссылки на [Forvo](https://forvo.com/languages/no/) (живой голос носителя) и [Ordbøkene](https://ordbokene.no/) (официальный словарь: род, формы).
* **Кнопки æ ø å** — если нет норвежской раскладки. В письме «почти верно, но без æ/ø/å» подсвечивается отдельно.
* **Автоперевод** norsk → русский и **примеры Tatoeba** (букмол ↔ русский).
* **Статистика:** стрик и цель дня, прогноз повторений, уровни, тепловая карта активности, трудные слова, история каждого слова.
* **Офлайн** (PWA), **импорт/экспорт** TXT, CSV, Anki, JSON-бэкап. **4 темы**: системная, тёмная, светлая, «Норд».

## 🚀 Запуск

Нужен Node.js 20.17 или новее.

```bash
git clone https://github.com/Whyslab/teach-me-english.git
cd teach-me-english
npm install
npm start
```

Открой <http://localhost:3000>. База `vocab.db` создаётся сама при первом запуске.

Чтобы приложение запускалось вместе с системой — `./deploy/install.sh` (systemd user-сервис, без sudo). Подробности и переменные окружения — в [README.md](README.md#-running-it-as-a-service).

### Импорт списка слов

«Импорт» → вставь текст или выбери `.txt`. Одна строка — одно слово:

```
hus|дом|Huset er stort.|Дом большой.|A1,hjem
eple|яблоко
å reise|путешествовать|||reise
```

Формат: `слово|перевод|пример|перевод примера|теги|род|формы`. Обязательны только первые два поля.

* **род:** `en` / `ei` / `et` — существительное; `v` — глагол. Можно и так: `et hus|дом` — род возьмётся из артикля.
* **формы** через запятую: существительное — «опр. ед., неопр. мн., опр. мн.» (`huset,hus,husene`), глагол — «presens, preteritum, perfektum» (`reiser,reiste,har reist`).

Пример строки с грамматикой: `bok|книга|Boka er fin.|Книга хорошая.|A1|ei|boka,bøker,bøkene`. Такой же формат даёт экспорт в TXT, так что словарь можно редактировать в текстовом редакторе и загружать обратно.

### Если озвучка звучит «по-английски»

Это значит, что в системе нет норвежского голоса. Установи его:

* **Windows:** Параметры → Время и язык → Речь → Добавить голоса → Norsk (bokmål).
* **macOS:** Системные настройки → Универсальный доступ → Устная речь → Системный голос → Управление голосами → Norwegian.
* **Android:** Настройки → Синтез речи → Google → Установить голосовые данные → Norsk.
* **Linux:** `espeak-ng` уже умеет `nb`; для Chrome нужен `speech-dispatcher`.

## 🧪 Тесты

```bash
npm test
```

72 теста на временной базе: API и раздача статики (база и исходники недоступны), синхронизация SM-2 и грамматики, SM-2 и выбор слов на сессию, проверка ответов (артикли, æ ø å, варианты перевода), подсказки форм, формат импорта/экспорта, целостность колоды A1 и статические проверки разметки (у каждого `data-action` есть обработчик, нет инлайн-скриптов).

## 🧩 Устройство фронтенда

Нативные ES-модули без сборщика, папка `js/`:

| Модуль | Что делает |
|---|---|
| `norsk.js` | грамматика букмола, проверка ответов, ссылки на словари (без DOM) |
| `srs.js` | SM-2, нормализация слов, выбор слов на сессию с лимитом новых (без DOM) |
| `format.js` | формат импорта, TXT/CSV/Anki (без DOM) |
| `store.js` | состояние, localStorage, синхронизация, стрик |
| `list.js`, `stats.js`, `training.js` | список слов, статистика, тренировка |
| `wordform.js`, `io.js`, `tatoeba.js`, `themes.js`, `ui.js` | форма слова, импорт/экспорт, примеры, темы, общие элементы |
| `main.js` | точка входа и реестр действий |

В разметке нет `onclick`: у кнопок есть `data-action`, а один обработчик в `main.js` находит действие в реестре.

## ⚠️ Ограничения

* **Нет аутентификации.** Не открывай порт в интернет.
* `POST /api/sync` заменяет весь словарь. С двумя устройствами побеждает последнее синхронизированное.
* Приложение переделано из английской версии: если в браузере или `vocab.db` остался английский словарь, он появится в списке — удали его через «Очистить всё» (сначала сделай бэкап).
