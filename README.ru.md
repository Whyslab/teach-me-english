Тренажёр норвежских слов (**букмол**) на интервальном повторении, который живёт на твоём компьютере. Добавляешь слово — приложение подтягивает перевод и примеры предложений, озвучивает слово норвежским голосом и само решает, когда показать его снова: прямо перед тем, как ты бы его забыл.

Ставится как приложение (PWA) и полностью работает без интернета. Интерфейс — на русском.

## ✨ Что умеет

* **Интервальное повторение SM-2** (как в Anki): четыре оценки — «Снова», «Сложно», «Хорошо», «Легко». Состояние каждого слова и история ответов хранятся на сервере.
* **Пять режимов тренировки:** карточки, письмо (видишь норвежское слово — пишешь перевод), «Угадай из 4», марафон без таймера, повтор ошибок.
* **Норвежское произношение.** Браузерный синтез речи с голосом `nb-NO`. Если в системе нет норвежского голоса, приложение предупредит.
* **Кнопки æ ø å** — для тех, у кого нет норвежской раскладки (с Shift — заглавные).
* **Автоперевод** норвежский → русский при вводе слова (MyMemory).
* **Примеры предложений** с [Tatoeba](https://tatoeba.org/) — пары букмол ↔ русский, в форму добавляются одним кликом.
* **Прогресс:** кривая по уровням, тепловая карта активности, график за неделю, прогноз повторений, XP, стрики, недельный челлендж, достижения.
* **Работает офлайн.** Service worker кеширует приложение; словарь живёт в браузере и синхронизируется с сервером, когда тот доступен.
* **Данные твои:** импорт/экспорт TXT, CSV, файл для Anki, полный JSON-бэкап.
* **Теги и фильтры** по тегу, уровню и поиску.

## 🚀 Запуск

Нужен Node.js 20.17 или новее.

```bash
git clone https://github.com/Whyslab/teach-me-english.git
cd teach-me-english
npm install
npm start
```

Открой <http://localhost:3000>. База `vocab.db` создаётся сама при первом запуске.

Чтобы приложение запускалось вместе с системой — `./deploy/install.sh` (systemd user-сервис, без sudo). Подробности и переменные окружения — в [README.md](README.md#-running-it-as-a-service).

### Импорт списка слов

«Импорт» → вставь текст или выбери `.txt`. Одна строка — одно слово:

```
hus|дом|Huset er stort.|Дом большой.|A1,hjem
eple|яблоко
å reise|путешествовать|||reise
```

Формат: `слово|перевод|пример|перевод примера|теги через запятую`. Обязательны только первые два поля.

### Если озвучка звучит «по-английски»

Это значит, что в системе нет норвежского голоса. Установи его:

* **Windows:** Параметры → Время и язык → Речь → Добавить голоса → Norsk (bokmål).
* **macOS:** Системные настройки → Универсальный доступ → Устная речь → Системный голос → Управление голосами → Norwegian.
* **Android:** Настройки → Синтез речи → Google → Установить голосовые данные → Norsk.
* **Linux:** `espeak-ng` уже умеет `nb`; для Chrome нужен `speech-dispatcher`.

## ⚠️ Ограничения

* **Нет аутентификации.** Не открывай порт в интернет.
* `POST /api/sync` заменяет весь словарь. С двумя устройствами побеждает последнее синхронизированное.
* Приложение переделано из английской версии: если в браузере или `vocab.db` остался английский словарь, он появится в списке — удали его через «Очистить всё» (сначала сделай бэкап).
