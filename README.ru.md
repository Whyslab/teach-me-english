Тренажёр норвежских слов (**букмол**) на интервальном повторении, который живёт на твоём компьютере. Добавляешь слово — приложение подтягивает перевод и примеры предложений, озвучивает слово норвежским голосом и само решает, когда показать его снова: прямо перед тем, как ты бы его забыл.

Ставится как приложение (PWA) и полностью работает без интернета. Интерфейс — на русском.

## ✨ Что умеет

* **Интервальное повторение SM-2** (как в Anki): две кнопки — «Не помню» (1 или ←) и «Помню» (2 или →). В расписание идёт только первый ответ за день: повторы внутри тренировки доучивают слово, но интервал не двигают. Интервалы от 3 дней разбрасываются на ±10 %, чтобы повторения не шли пачками. Интервалы и история ответов хранятся на сервере.
* **Лимит новых слов в день** (по умолчанию 15, как в Anki). Повторения не ограничены, так что после импорта большой колоды не случится завала через неделю.
* **Основная тренировка и практика.** Основная тренировка (и марафон) идёт по расписанию SM-2 и учитывает лимит новых слов. Все остальные режимы — **практика**: доступны всегда, 20 слов (сначала те, что пора повторить, потом самые трудные), расписание не меняют.
* **«❓ Как это работает»** — окно прямо в приложении: что такое уровни 0–5, когда слово считается выученным (интервал от 21 дня — это 4 ответа «Помню» подряд в разные дни), чем практика отличается от тренировки.
* **Грамматика:** род существительного (`en` / `ei` / `et`, цветом) и формы: *et hus — huset — hus — husene*, *å reise — reiser — reiste — har reist*, *stor — stort — store*. Кнопка «⚡ формы по правилу» заполняет регулярные формы существительных и прилагательных.
* **Режимы тренировки:** карточки (по умолчанию NO→RU; в настройках RU→NO или вперемешку) · письмо NO→RU · письмо RU→NO (для экзамена) · **диктант** · «Угадай из 4» · **«Угадай род»** · **«Формы»** · **«Пропуски»** (слово вырезано из примера) · трудные слова · марафон без лимита.
* **Колоды Norsk A1** (275 слов) и **Norsk A2** (342 слова, без повторов с A1) — с родом, формами, примерами и переводом, добавляются одной кнопкой в окне «Импорт». Повторный импорт колоды дополняет род, формы и примеры у уже добавленных слов, прогресс не трогает.
* **Произношение:** нейросетевой голос Piper (локально, см. «Озвучка» ниже; без него — браузерный синтез) + ссылки на [Forvo](https://forvo.com/languages/no/) (живой голос носителя) и [Ordbøkene](https://ordbokene.no/) (официальный словарь: род, формы).
* **Кнопки æ ø å** — если нет норвежской раскладки. В письме «почти верно, но без æ/ø/å» подсвечивается отдельно.
* **Автоперевод** norsk → русский (выключен по умолчанию, включается в настройках) и **примеры Tatoeba** (букмол ↔ русский).
* **Статистика:** стрик и цель дня, прогноз повторений, уровни, тепловая карта активности, трудные слова, история каждого слова.
* **Ежедневный бэкап базы** в `~/Backups/teach-me-norwegian` (хранятся 14 последних копий).
* **Офлайн** (PWA), **импорт/экспорт** TXT, CSV, Anki, JSON-бэкап. **4 темы**: системная, тёмная, светлая, «Норд».

## 🚀 Запуск

Нужен Node.js 20.17 или новее.

```bash
git clone https://github.com/Whyslab/teach-me-english.git
cd teach-me-english
npm install
npm start
```

Открой <http://localhost:3000>. База `vocab.db` создаётся сама при первом запуске.

Чтобы приложение запускалось вместе с системой — `./deploy/install.sh` (systemd user-сервис, без sudo). Подробности и переменные окружения — в [README.md](README.md#-running-it-as-a-service).

### Импорт списка слов

«Импорт» → вставь текст или выбери `.txt`. Одна строка — одно слово:

```
hus|дом|Huset er stort.|Дом большой.|A1,hjem
eple|яблоко
å reise|путешествовать|||reise
```

Формат: `слово|перевод|пример|перевод примера|теги|род|формы`. Обязательны только первые два поля.

* **род:** `en` / `ei` / `et` — существительное; `v` — глагол; `a` — прилагательное. Можно и так: `et hus|дом` — род возьмётся из артикля.
* **формы** через запятую: существительное — «опр. ед., неопр. мн., опр. мн.» (`huset,hus,husene`), глагол — «presens, preteritum, perfektum» (`reiser,reiste,har reist`), прилагательное — «ср. род, мн. ч./опр.» (`stort,store`).

Пример строки с грамматикой: `bok|книга|Boka er fin.|Книга хорошая.|A1|ei|boka,bøker,bøkene`. Такой же формат даёт экспорт в TXT, так что словарь можно редактировать в текстовом редакторе и загружать обратно.

### Озвучка: нейросетевой голос Piper

Браузер на Linux озвучивает через `espeak-ng` — это звучит роботом. Поэтому
приложение умеет говорить голосом [Piper](https://github.com/OHF-Voice/piper1-gpl):
локальный нейросетевой синтез, без интернета и ключей, модель `no_NO-talesyntese-medium`.

```bash
./deploy/install-voice.sh
```

Скрипт ставит Piper в `.venv-tts/`, скачивает модель (~60 МБ) в `voices/`,
проигрывает пробную фразу и перезапускает службу. Sudo не нужен. Если pip не
сможет поставить Piper под свежий Python, скрипт попросит поставить `uv`
(`sudo pacman -S uv`) — тот сам возьмёт подходящую версию Python.

Каждое слово синтезируется один раз (около секунды) и кешируется в `tts-cache/`;
во время тренировки звук следующих карточек готовится заранее. Модель держит
загруженной постоянный процесс (`tts_worker.py`), поэтому новое слово звучит
почти сразу. Скорость речи — ползунок в ⚙️ настройках. Если Piper не
установлен, приложение говорит браузерным голосом, как раньше.
Удалить голос: `rm -rf .venv-tts voices tts-cache`.

Переменные окружения (необязательно): `PIPER_BIN`, `PIPER_MODEL`, `PIPER_WORKER` (пустая строка — без постоянного процесса), `TTS_CACHE_DIR`.

## 🧪 Тесты

```bash
npm test            # модульные тесты и API
npm run test:e2e    # тесты в настоящем браузере (Playwright + Chromium)
```

`npm test` — на временной базе: API и раздача статики (база и исходники недоступны), синхронизация SM-2 и грамматики, SM-2 и выбор слов на сессию, проверка ответов (артикли, æ ø å, варианты перевода), подсказки форм, формат импорта/экспорта, целостность колод A1 и A2, дополнение грамматики при повторном импорте, синхронизация по изменениям, протокол воркера Piper, бэкап и статические проверки разметки (у каждого `data-action` есть обработчик, нет инлайн-скриптов).

## 🧩 Устройство фронтенда

Нативные ES-модули без сборщика, папка `js/`:

| Модуль | Что делает |
|---|---|
| `norsk.js` | грамматика букмола, проверка ответов, ссылки на словари (без DOM) |
| `srs.js` | SM-2, нормализация слов, выбор слов на сессию с лимитом новых (без DOM) |
| `format.js` | формат импорта, TXT/CSV/Anki (без DOM) |
| `store.js` | состояние, localStorage, синхронизация, стрик |
| `sync.js` | вычисление изменений для синхронизации (без DOM) |
| `list.js`, `stats.js` | список слов, статистика |
| `training.js`, `session.js`, `mode-*.js`, `results.js` | тренировка: запуск, состояние сессии, режимы, итоги |
| `wordform.js`, `io.js`, `tatoeba.js`, `themes.js`, `ui.js` | форма слова, импорт/экспорт, примеры, темы, общие элементы |
| `main.js` | точка входа и реестр действий |

В разметке нет `onclick`: у кнопок есть `data-action`, а один обработчик в `main.js` находит действие в реестре.

## ⚠️ Ограничения

* **Нет аутентификации.** Не открывай порт в интернет.
* С двух устройств, правивших одно и то же слово без сети, побеждает то, что синхронизировалось последним.
* Приложение переделано из английской версии: если в браузере или `vocab.db` остался английский словарь, он появится в списке — удали его через «Очистить всё» (сначала сделай бэкап).
